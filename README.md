# TapeDrift

TapeDrift is a Cloud-based Stream Manager that enables real-time data processing through auto-scaling Processor clusters.

The key benefits of using TapeDrift include:

- TapeDrift is a Cloud-based Stream
- Manager that enables real-time data
- processing through auto-scaling Processor clusters

## Key Features

- TapeDrift is a Cloud-based Stream
- Manager that enables real-time data
- processing through auto-scaling Processor clusters

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/TapeDrift.git`
2. `cd TapeDrift`
3. Install in editable mode: `pip install -e .`

## Configuration

TapeDrift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
